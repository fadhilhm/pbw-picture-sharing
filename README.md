# picturesharing

Rekomendasi gw untuk yang kerja, coba install Docker Desktop (Windows/MacOS) atau Docker Engine (Linux). 

Kemudian run: `docker compose up -d`, ini dipake buat database. Nanti run App kayak biasa

Buat delete atau restart data run: `docker compose down -v`. Ini dipake incase ERD-nya salah heheha
